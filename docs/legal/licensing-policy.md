# Licensing Policy (DRAFT — PREPARED-ONLY, not effective)

> Status: **DRAFT**. This policy is **proposed only** and creates no
> obligations. No root `LICENSE` / `COPYING` / `NOTICE` is published as
> effective by this slice. The official AGPL text has **not** yet been fetched
> from `https://www.gnu.org/licenses/agpl-3.0.txt` (see
> `LICENSE.AGPL-3.0.prepared`). No source headers have been added. No action
> under this draft may be treated as enforcement.

## Proposed terms

1. Code: SPDX expression **AGPL-3.0-or-later** is **PROPOSED** for original
   code authored in or contributed to the LibrePeople project. This is a
   proposal only; the licence is not yet granted, noticed, or effective.
2. Original docs: **CC BY 4.0 PROPOSED** for original documentation only.
   Scope confirmation is pending (see unresolved-blocker register). This
   proposal covers only original docs; it does not touch third-party material.
3. Third-party material: all third-party code, packages, base images, fonts,
   and docs remain under their own upstream terms, unchanged by this draft.
   Nothing in this file alters, replaces, or re-states any third-party term.
   The existing inventories under `docs/licensing/` remain the reference; see
   `third-party-licences.md`.
4. Karmathy-marked assets (`karmathy-backend`, `karmathy-frontend`,
   `© 2026 Karmathy` footer and brand mentions): transfer to the LibrePeople
   project is **UNRESOLVED**. No use, rename, or rights assertion is authorised
   by this draft until a legal reviewer signs off with written evidence.

## What this slice does not do

- Publish any effective licence file at the repo root.
- Insert any `SPDX-License-Identifier` or copyright header into any source.
- Add, remove, or upgrade any dependency.
- Change repo visibility (report-only; unchanged — see governance note).
- Claim any trademark assignment or removal.
- Claim any endorsement by the GNU project or the Free Software Foundation.
