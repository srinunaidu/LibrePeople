This folder holds two files: `PRD.md`, the LibrePeople Complete Product Requirements Document v1.0 (Review), converted from the product-owner DOCX without changes to requirement IDs or acceptance criteria, and `requirements-traceability.csv`, the traceability register with one row per requirement ID (136 rows). The PRD governs over any other proposal, and where another document conflicts with it, the conflict must be raised for product-owner decision rather than resolved by reinterpretation. At this commit every row in the traceability register has the status NOT STARTED, and the register asserts no implementation progress. The reference proposal "Requirement India.txt" in the workspace is NOT an approved source and must not be treated as a requirements baseline; its contents are deliberately not copied into this repository. Open decisions are listed in section 29 of the PRD.
